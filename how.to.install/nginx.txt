Q. How to enable ssl for ngnix server on Linux with self-signed certificate
A. 

1. Install OpenSSL (usually already installed)

	sudo yum install -y openssl   # Amazon Linux 2
	# OR
	sudo dnf install -y openssl   # Amazon Linux 2023

2. Generate self-signed certificate
	sudo mkdir -p /etc/nginx/ssl
	sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
	-keyout /etc/nginx/ssl/nginx.key \
	-out /etc/nginx/ssl/nginx.crt

3. Configure Nginx for SSL

	sudo nano /etc/nginx/conf.d/default.conf

Add/modify:

server {
    listen 80;
    server_name _;

    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name _;

    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        root /usr/share/nginx/html;
        index index.html;
    }
}

4. Test config

	sudo nginx -t

5. Restart Nginx
	sudo systemctl restart nginx

Access your site

	https://<your-ec2-public-ip>

Q. How to deploy website on ngnix server
A. 
Step 1: Install & Start Nginx
	
	sudo dnf install nginx -y      # Amazon Linux 2023
	# OR
	sudo amazon-linux-extras install nginx1 -y   # Amazon Linux 2

	sudo systemctl start nginx
	sudo systemctl enable nginx

Step 2: Check default web directory


	/usr/share/nginx/html/

Step 3: Add your website files

	cd /usr/share/nginx/html

Option B: Copy your project files

	sudo cp -r /path-to-your-project/* /usr/share/nginx/html/

Step 4: Set permissions

	sudo chmod -R 755 /usr/share/nginx/html

Step 5: Restart Nginx

	sudo systemctl restart nginx

Step 6: Open in browser

	http://<your-ec2-public-ip>
